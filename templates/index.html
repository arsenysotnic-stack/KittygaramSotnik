Kittygram — управление котиками

Основной проект: регистрация котиков, их достижения, хозяева

Котики

Добавляйте котиков с именем, цветом, годом рождения. Каждый котик привязан к хозяину и защищён от чужого редактирования.

Достижения

Отмечайте подвиги котиков: «уронил ёлку», «поймал мышку», «разбил вазу». Связь многие-ко-многим.

Пользователи

Регистрация через API, токен-аутентификация. Только хозяин может редактировать и удалять своих котиков.

Паспорт здоровья — медкарта кота

Расширение Kittygram: ведение медицинских записей и список клиник

1. Зарегистрируй кота

Создай профиль питомца: имя, цвет, год рождения. Без этого нельзя завести медкарту.

2. Веди медкарту

Прививки, осмотры, диагнозы. Привяжи запись к клинике и сохрани историю обращений.

3. Клиники

Справочник ветклиник с адресом и телефоном. Можно фильтровать записи по клинике.

Технологии

Django + DRF

Python 3.10, Django 4.2, Django REST Framework 3.14. Сериализаторы, вьюсеты, роутеры, пермишены.

Djoser + Token

Авторизация через токены DRF. Регистрация и управление пользователями через Djoser.

Swagger через drf-yasg

Автоматическая документация API: Swagger UI и Redoc. Фильтрация через django-filter.
